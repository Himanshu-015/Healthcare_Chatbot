# 🏥 Healthcare Chatbot using Machine Learning

An AI-powered healthcare chatbot that predicts possible diseases based on symptoms provided by the user.

---

## 🚀 Features

- Symptom-based disease prediction
- Machine Learning integration
- Decision Tree Classifier
- SVM Model Accuracy Testing
- Disease precaution suggestions
- Health condition severity analysis
- Interactive chatbot interface

---

## 🛠 Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Decision Tree Algorithm
- Support Vector Machine (SVM)
- Pyttsx3

---

## 📂 Project Structure

```bash
healthcare-chatbot/
│
├── Data/

```

## ▶️ How to Run

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Project

```bash
python chatbot.py
```
